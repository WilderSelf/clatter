Mobile shell — option F: four phase tabs

A persistent header carries four phase tabs. The selected tab changes on its own when the phase changes, so the strip is not only navigation. The middle area draws one tab at a time. A persistent footer carries More, Roll again and Push.

The roll pane is drawn in the table phase after one push, so the strip shows a tab the app picked and not one the player picked. The second pane draws the strip before any roll, where three of the four tabs have nothing behind them.

The pool holds the maximum of 25 dice: 15 pool dice and 10 stress dice. The faces and the lock mix are the same ones option C drew, so the six options stay comparable. Each frame is a device viewport with a fixed height, so a screen that does not fit must scroll inside the middle area.
