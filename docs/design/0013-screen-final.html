Screen — the settled design

This drawing joins the option C tray to the option G shell and applies six owner decisions. The faces, the lock mix and the pool order inside each zone are the ones every earlier option drew, so the drawings stay comparable.

  1. The pool chip is gone after a roll. The tray takes the whole middle.
  2. The difficulty rides on the Roll again button, beside the dice count.
  3. Edit pool sits on the cost row, which the screen already had. It reopens the builder.
  4. Every minus and plus end is 44 px wide. The builder holds two columns at phone width and scrolls, because a builder is a form.
  5. One export control lives in the record detail, in the footer.
  6. The footer reserves env(safe-area-inset-bottom). The phone frames force a 34 px inset and draw a home indicator inside it.

Each frame is a device viewport with a fixed height, so a screen that does not fit must scroll inside its middle area. The phone is drawn twice: 760 px tall for standalone mode, and 660 px tall for a browser tab, which loses about 100 px to browser chrome.
