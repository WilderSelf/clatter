Mobile shell — option G: status header and one surface

The header is status, not navigation. One line holds successes, banes, dice count, stress and push count. It never moves and it never changes what it holds. Only the numbers change. Nothing in it is tappable.

The middle is one surface. The pool builder collapses to a summary chip once the dice are on the table, and the tray takes the space the collapse frees. A tap on the chip opens the builder again. Both states are drawn below.

The footer is option C unchanged: More, Roll again and Push, with the push cost on the Push button. History is a separate destination reached from More. It is not a peer of the roll flow, so it replaces the screen and it carries its own back control.

The pool holds the maximum of 25 dice: 15 pool dice and 10 stress dice. The faces and the lock mix are the same ones option C drew, and pool order is kept inside each zone, so the options stay comparable. Each frame is a device viewport with a fixed height, so a screen that does not fit must scroll inside the middle area.
